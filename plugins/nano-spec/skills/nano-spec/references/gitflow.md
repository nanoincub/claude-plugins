# Gitflow

> **Conteúdo movido.** O fluxo completo de gitflow (HARD BLOCK git-flow-next, comandos
> `git flow start/finish`, branches protegidas, naming semver) agora vive na skill
> [`nano-spec:nano-commit`](../../nano-commit/SKILL.md), junto com o fluxo de commit.
>
> **Como usar:**
> - O orquestrador `nano-spec` invoca `Skill('nano-spec:nano-commit')` na fase Commit.
> - Para invocar standalone (só commitar, criar branch, fazer PR, sem entrar no fluxo
>   completo de spec), basta pedir "commitar", "criar branch", "fazer PR", etc. — a skill
>   é auto-disparada via description.
>
> Este pointer existe apenas para compatibilidade com links antigos do orquestrador.
